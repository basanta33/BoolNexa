BoolNexa Academy v1.1.2 — Visual Symbols Release
=================================================

This replacement package removes administrative dashboard statistics and hour badges from the Academy home page.

Added:
- Standard logic-symbol strip for NOT, AND, OR, XOR, NAND and NOR.
- Dedicated visual illustration for every learning pathway.
- Binary lesson hero illustration showing 1010₂ = 10₁₀.
- Logic LOW and Logic HIGH visual concept cards.
- Image alternative text for accessibility.
- Learning Path wording in place of Curriculum dashboard wording.

The artwork is supplied as original, lightweight SVG assets. It remains sharp at every screen size and does not rely on external image hosting.

Install:
1. Back up D:\Projects\BoolNexa.
2. Extract this package into D:\Projects\BoolNexa.
3. Replace files when prompted.
4. Run tests and then Reflex.

Commands:
D:\Projects\BoolNexa\.venv\Scripts\python.exe -m pytest -q
D:\Projects\BoolNexa\.venv\Scripts\python.exe -m reflex run
